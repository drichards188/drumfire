# Contributing to Drumfire

Contributions are welcome, here in this repository.

Drumfire is source-available, not open source. Its [licence](LICENSE) (PolyForm Strict 1.0.0) lets you play and study it for non-commercial purposes. It does not let you change it, publish your own version of it, or use it commercially.

## Permission to contribute

As an exception to the licence, you may fork this repository on GitHub and change your fork, only to propose those changes back to this repository as pull requests. This permission does not cover publishing, distributing or using a changed version for anything else.

## Your contribution

By opening a pull request, you agree that:

- the contribution is your own work, or you have the right to submit it;
- you grant David Richards a perpetual, worldwide, non-exclusive, royalty-free, irrevocable licence to use, change, distribute and sublicense it under any terms, including commercially and under other licences;
- you keep your own copyright in it.

## How

- Open an issue first for anything large, so we can agree on the approach.
- [Development](docs/DEVELOPMENT.md) has the tests, tools and dev pages; [DESIGN.md](DESIGN.md) has the contract between the modules.
- If you change the simulation, run the headless tests in `tools/` before and after and say in the pull request what changed.
